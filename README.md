# Shubh Deepavali ✨

A cinematic, responsive Diwali greeting experience built with React, Vite, Three.js and React Three Fiber.

## Features

- Immersive 3D diya with a softly animated flame and warm light.
- Procedural starfield, floating particles and decorative mandala details.
- Elegant editorial typography and a warm midnight palette.
- Responsive sections for blessings, festive wishes and values.
- Personalised greeting copy flow with clipboard sharing.
- Motion effects with reduced-motion preference support.
- No backend, database, API key or environment variables required.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`. Deploy the project to Vercel, Netlify or GitHub Pages using the Vite build command.

## Stack

- React 19 + Vite
- Three.js + React Three Fiber + Drei
- Framer Motion
- Lucide React
